# Releasetools — TECNO POVA 6 Pro 5G (LI9)

`releasetools.py` provides the standard AOSP/LineageOS OTA extension hooks (`FullOTA_InstallEnd`, `IncrementalOTA_InstallEnd`) referenced by `TARGET_RELEASETOOLS_EXTENSIONS` in `BoardConfig.mk`.

Because LI9 uses Virtual A/B (`AB_OTA_UPDATER := true`) with dynamic partitions (`super`), standard partition updates are generated by `ota_from_target_files` / `brillo_update_payload`. Low-level MediaTek firmware partitions (`preloader`, `lk`, `md1img`, `tee`, `scp`, `sspm`, `spmfw`, `dpm`, `mcupm`, `gz`) are intentionally not flashed automatically unless explicitly verified on hardware.
